This project is supposed to simulate the look of Windows XP (as opposed to an emulator, 
which would act as an engine to actually launch it). This is a recreation through my 
interpretation for a SoftUni exam for the course Django Basics.  
  
You can launch it through the run.bat file that has been put outside any directories. 
The app has the following capabilities:

- Storing files, folders and shortcuts.
- Opening folders and seeing their structure.
- Opening files and seeing their contents.
- Opening shortcuts to visit the file/folder's location.
- An optimized desktop, showing files that are on Disk C.
- An optimized taskbar with a start menu that has a Restart and Shutdown functionality
  and a File Manager icon that opens the File Manager.
